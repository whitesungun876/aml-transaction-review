# Provenance and redistribution boundaries

This personal portfolio was developed with Codex assistance. Repository ownership is not evidence of unaided implementation or production banking experience.

`src/erp_risk/evaluation.py` is copied unchanged from the same author's [ERP Risk MLOps](https://github.com/whitesungun876/erp-risk-mlops/blob/2d519d8f3071a19c881ae049b55e2ebccdd31860/src/erp_risk/evaluation.py), Git blob `36865204a2c1edbbe207caccabf020955cff63ac`. Its original package initialiser is replaced by an empty portable initialiser. All AML-specific parsing, temporal features and cloud contracts remain separate.

No new open-source licence is assigned in this publication; public visibility alone is not a general redistribution licence. The upstream ERP repository had no explicit licence at publication.

IBM AML data is obtained separately from the provider linked in the data card. The selected release metadata identifies CDLA Sharing 1.0; review the provider's current terms before use or redistribution. No provider CSV, transaction-level derivative or trained model binary is included here. Test fixtures are manually constructed examples.
